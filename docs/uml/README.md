# UML del proyecto Biblioteca

Los seis diagramas muestran el código local de la aplicación compilado con JDK 26. Las fichas incluyen miembros declarados, visibilidad, modificadores y firmas Java. `+` público, `-` privado, `#` protegido y `~` acceso de paquete. Se omiten métodos sintéticos del compilador y clases anónimas de Swing. Los prefijos de paquete de Java se omiten para facilitar la lectura. Las relaciones por ID no son referencias a objetos.

Para la presentación, comienza por **06-diagrama-general.png** y usa las demás imágenes para consultar los detalles:

1. `01-modelo.png`: clases Usuario, Libro, Préstamo y DetallePrestamo.
2. `02-servicios.png`: operaciones y persistencia.
3. `03-vistas.png`: ventanas principales y navegación.
4. `04-inicio-paneles-excepciones.png`: inicio, paneles y errores.
5. `05-relaciones.png`: relaciones y dependencias.
6. `06-diagrama-general.png`: vista general.
